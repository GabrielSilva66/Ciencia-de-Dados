# 📊 Ciência de Dados

Repositório dedicado ao conteúdo, roteiros e atividades práticas da **Unidade 2** da disciplina de **Ciência de Dados**. O foco desta unidade é construir uma base sólida em análise de dados, reprodutibilidade científica, manipulação de dados tabulares e métodos estatísticos.

---


## 📂 Estrutura do Repositório

```text
├── aulas/                          # Roteiros teóricos e práticos das aulas (.qmd)
│   ├── Aulas.qmd
│   └── [datasets]/                 # Conjuntos de dados das aulas (penguins, iris, titanic, etc.)
│
├── unidade_2/                        # Espaço reservado para exercícios da unidade 2
│
└── README.md                       # Documentação e guia da unidade
```

## 🛠️ Tecnologias e Ferramentas

- **Linguagens:** Python 3 (principal) e R (comparativo)

- **Bibliotecas Principais:**
  - Manipulação e análise: `pandas`, `numpy`
  - Visualização: `matplotlib`, `seaborn`
  - Estatística e modelagem: `scipy`, `statsmodels`, `scikit-learn`
- **Controle de Versão:** Git & GitHub

# 📊 Ciência de Dados

Repositório dedicado ao conteúdo, roteiros e atividades práticas da **Unidade 2** da disciplina de **Ciência de Dados**. O foco desta unidade é construir uma base sólida em análise de dados, reprodutibilidade científica, manipulação de dados tabulares e métodos estatísticos.

---

## 🎯 Objetivos da Unidade

- **Construir um ambiente de desenvolvimento reprodutível:** Dominar boas práticas essenciais de isolamento de ambientes virtuais, controle de dependências e versionamento com Git.
- **Manipular e explorar dados tabulares:** Carregar, transformar, filtrar e agregar conjuntos de dados reais em Python (e estudos comparativos em R).
- **Tratamento e pré-processamento de dados:** Lidar com dados ausentes (imputação), identificar discrepâncias e aplicar técnicas de normalização e padronização.
- **Análise e inferência estatística:** Aplicar conceitos fundamentais de estatística descritiva, distribuições de probabilidade, intervalos de confiança e testes de hipóteses paramétricos para tomada de decisão fundamentada em dados.
